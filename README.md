# Unit Converter

A unit conversion application built with C++ that allows users to convert values between different units of measurement.

## Overview

The goal of this project is to develop a practical unit converter while strengthening my C++ programming skills, problem-solving abilities, and understanding of software development fundamentals.

## Planned Features

- [ ] Length conversions (meters, kilometers, miles, feet, etc.).
- [ ] Mass and weight conversions (grams, kilograms, pounds, etc.).
- [ ] Temperature conversions (Celsius, Fahrenheit, Kelvin).
- [ ] Volume conversions (liters, milliliters, gallons, etc.).
- [ ] Interactive menu for selecting conversion categories.
- [ ] Input validation and error handling.
- [ ] Support for less common units of measurement.

## Technologies

- C++
- Standard Template Library (STL)

## Getting Started

### Prerequisites

- A C++ compiler that supports C++17 or later.
- A terminal or command-line interface.

### Compilation

Compile the source code using `g++`:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o unit-converter
```

### Execution

On macOS or Linux:

```bash
./unit-converter
```

On Windows:

```bash
unit-converter.exe
```
